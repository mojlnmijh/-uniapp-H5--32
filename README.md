# 全伐在线教育知识付费小程序源码网站系统（带数据uniapp支持发布H5和小程序）
获取源码：ym7k.com/11811/
“全伐在线教育知识付费小程序源码网站系统”是一套基于 uniapp 开发的在线教育知识付费解决方案，支持发布 H5 和小程序，并附带数据，适合快速搭建知识付费平台。

核心功能模块：

内容形态：图文、音频、视频、专栏、直播、电子书，支持试看、加密、防下载。

付费体系：单课购买、专栏订阅、会员卡、SVIP、积分兑换、优惠券、拼团、秒杀。

分销裂变：三级分销、推广海报、邀请返佣、佣金提现，驱动用户裂变拉新。

用户中心：学习记录、收藏、订单、已购课程、证书、打卡、评论互动。

直播互动：对接第三方直播或自建直播，支持连麦、打赏、回放。

后台管理：内容审核、订单管理、用户管理、财务流水、数据统计、分销配置。

技术架构：

前端：uniapp 一套代码编译 H5 + 微信小程序 + App

后端：通常为 ThinkPHP / Java + MySQL + Redis

部署：支持宝塔面板一键部署，配 Nginx + PHP + MySQL 环境
